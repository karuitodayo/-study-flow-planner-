# Study Flow Planner

学習・勤務・案件（デザインコンペ／受注案件）を1つの画面で管理する、個人用の学習支援ダッシュボードです。

> **このリポジトリについて**
> 本リポジトリは課題提出用に、アプリ全体のソースコードから**重要な処理のみを抜粋して再構成したもの**です。
> アプリ全体のソースコード・データベース・認証情報は含まれていません。詳しくは [公開しているコードの説明](#公開しているコードの説明) を参照してください。

---

## 制作目的

AI学習の時間確保を軸に、勤務シフトや案件の締切と衝突しないように学習スケジュールを自動生成することを目的として制作しました。学習・勤務・案件を別々のツールで管理すると全体像が把握しづらくなるため、1つのダッシュボードに統合しています。

## 主な機能

| 機能 | 内容 |
|---|---|
| ダッシュボード | 今日の勤務区分・学習実績/予定・予定完了件数、今日の学習予定・タスク・ドリル、週次/月次目標の進捗、締切が近い案件を表示 |
| 目標管理 | 月間目標→週間目標の階層管理。達成条件チェックリスト、タスク連携、翌月/翌週への引き継ぎ |
| 学習タスク管理 | タスクの登録・一覧上でのその場編集 |
| デザインドリル管理 | LP/Instagram制作ドリルの管理。Markdown/ZIP取り込みと自動解析、論理削除（アーカイブ）と復元 |
| カレンダー | Google Calendar（読み取り専用）・アプリ内シフト・学習予定の統合表示。空き時間の可視化、学習スケジュールの自動生成（単日・週/月単位） |
| 学習記録（PDCA日報） | 日次日報の記入・保存、タスク単位の実績ログ、週次振り返り、PDF/Markdown出力 |
| 設定 | Google Calendar連携設定、生活時間、AI学習の目標時間、配置上限などの登録 |
| シフト登録 | 勤務日の一括登録、シフト表画像のOCR取り込み（試験提供） |
| 案件管理 | デザインコンペ/固定報酬案件/継続案件の管理、制作タスクの自動生成、締切逆算の実現可能性チェック |
| 学習タイマー | 学習タスク・ドリル・受注案件タスクの作業時間を計測し、実績として保存 |

## 使用技術

| 区分 | 技術 |
|---|---|
| アプリケーションフレームワーク | Streamlit |
| データ保存 | SQLite |
| 外部連携 | Google Calendar API（OAuth 2.0、読み取り専用） |
| 画像認識 | Tesseract OCR（pytesseract） + OpenCV |
| カレンダーUI | streamlit-calendar |
| PDF生成 | reportlab（日本語フォントを自動検出して埋め込み） |
| データ集計・表示 | pandas |
| 設定管理 | python-dotenv / PyYAML |

## 公開しているコードの説明

**今回は、アプリ全体のソースコードではなく、重要な処理のみを抜粋して公開しています。**
抜粋コードは元の実装を正確に反映しており、架空の処理は追加していません。それぞれ元ファイル名と処理内容をファイル冒頭のコメントに記載しています。

```
├── README.md                             本ファイル
├── docs/
│   └── implementation-spec.md            実装仕様の整理（目的・機能・使用技術・変更点）
└── code-samples/
    ├── schedule_generator.py             元: services/schedule_generator.py
    │                                      勤務時間・空き時間を考慮した学習スケジュール自動生成の中心処理
    ├── timer.py                          元: services/timer.py
    │                                      作業時間の計測・一時停止・再開に関する処理
    └── daily_report_pdf.py               元: services/daily_reports.py（PDF出力部分の抜粋）
                                           保存済み日報からPDFを生成する処理
```

各ファイルで掲載を省略した部分（データベース接続処理、他の抜粋対象ではないサービス層など）は、各ファイル冒頭のコメントに理由を明記しています。

### 掲載していないもの

- アプリ全体のソースコード（上記3ファイル以外の画面・業務ロジック）
- SQLiteデータベースの実データ・バックアップ
- APIキー・認証トークン・OAuth認証情報
- 個人の勤務シフト・学習記録・日報の内容
- ログ・キャッシュ・一時ファイル
